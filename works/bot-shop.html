Aura Wear Shop Bot

An Instagram comment that becomes an order. The bot answers in Direct, takes the buyer through checkout and tells them where the parcel is.

ForA clothing shop that sells through Instagram: shoppers who comment "ціна" and want to buy in two minutes, and the owner who ships the parcels.

01 · CLIENT AND ORDER

A comment becomes an order

A shopper comments "ціна?" under a post. The bot answers in Direct with colours, sizes and an order button, then walks through checkout with Nova Poshta branch search inside the chat.

Design decisions

  • The first reply is built from the post the shopper commented on, so the right product opens without a search.
  • One branch match gets a "Це воно?" check with the address. Several matches become a numbered list.
  • Stock is reserved at checkout and returned on cancel. A size that is out gets "Чекати на розмір" and a waitlist.
  • The bot polls Nova Poshta every 2 hours and writes when the parcel is shipped, at the branch and received.

AI try-on

A customer sends a photo and picks an item. The bot returns the photo with that item on, using Google Gemini image models through OpenRouter, with a fallback model and a photo check. The owner sets the limits: per buyer per day and per shop per month. A separate AI stylist suggests outfits for an occasion. This page shows no generated photo of a person.

The owner panel shows the funnel: comments, dialogues, carts, orders. It also lists best sellers, low stock and orders, and links Instagram posts to products.

SECURITY IN THIS BOT

What keeps this bot safe

Checked in the code on 12 November 2026. Each line says what the guard is and what goes wrong without it.

Mini App sign-in is checked with HMAC-SHA256

Telegram signs the data it gives a Mini App. The bot rebuilds the signature from a key derived from its own token, compares it in constant time, validates the user object and ends the session after 2 days. Without this check, anyone could open the owner panel by sending someone else's Telegram id.

Payment and Instagram webhooks need valid signatures

WayForPay and Instagram each sign what they send. Without the check, a stranger could post a fake "paid" notice or fake comments and Direct messages.

Parameterised SQL

User text goes into queries as values, never as query text, so a client who types SQL into a name field only gets a strange name. Product fields can be written only from an allowed list, so a request cannot touch a column nobody meant to expose.

All user text is escaped before it enters a Telegram HTML message

About 118 call sites. A buyer who types an HTML tag in a name or an address gets that text shown as typed.

AI try-on spend is capped

Every try-on costs money. Each buyer gets 3 a day by default and the shop 300 a month, and the owner can change both caps. One keen buyer, or a script, cannot run up the bill.

Stock is reserved at checkout and returned on cancel

Two buyers cannot both buy the last hoodie. If an order is cancelled, the item goes back on sale.

Tokens and keys come from environment variables

No secret is in the code, so sharing or backing up the code never leaks a key.

Still to harden in this bot

  • No automated tests yet. Next: tests for payments and stock reservation.
  • Versions were kept as .bak files on the server. Next: git with a private remote and checks on every push.

Server-wide measures and the full audit are in How I keep all four safe.
