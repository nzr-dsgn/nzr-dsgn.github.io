PRINCIPLES

Four decisions everything follows

1

Calm by default

Neutral surfaces, one brand colour, motion that explains. Colour is spent only where a decision needs it.

2

AI is visibly AI

One reserved hue and one border style mark what a machine proposed. A tenant never wonders who wrote it.

3

State is never colour alone

Every status carries an icon and a word. The palette still works for people who can't tell green from red.

4

Every action can be undone or previewed

Components ship with the preview and undo patterns built in, so product teams inherit them.

COLOUR

Roles, not swatches

Colour is defined by what it does. Every pair below shows its measured contrast, calculated in your browser from the current values.

MOTION

Duration and easing are tokens too

Click any track to play it. Switch Motion to Reduced in the controls above and every duration drops to zero, the way a user's system setting would.

ACCESSIBILITY

Built in, not added later

Contrast is measured

Body text and controls target 4.5:1 or better. The table in the Colour section is computed live, so changing the hue can't quietly break it.

Focus is always visible

A 2px outline in a dedicated focus colour, offset by 2px, on every interactive element. Try Tab on this page.

Touch targets

40px minimum on web, 48px on mobile. Small buttons sit inside a larger tap area.

Status beyond colour

Icons and words accompany every status colour. Badges read "Done", "Pending", "Not sent".

Live regions

The assistant thread and toasts announce changes politely, so screen readers hear what a sighted user sees.

Reduced motion

Respecting the system setting is built into the tokens, so no product team has to remember it.
